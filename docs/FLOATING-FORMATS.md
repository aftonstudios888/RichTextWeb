# Floating content interchange

`Figure` and `Floater` child stories are reusable model content, including paragraphs, inline formatting, links, lists and tables. Their main-story selection positions remain atomic while import/export reads the visible child story content.

| Format                           | Floating content behavior                                                                                                                                                                                                                                                                                                                                                                                          |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Canonical JSON and native bridge | Preserve complete Figure/Floater child trees, identities, table columns and portable layout properties. Bridge validation counts table columns toward node/depth limits and rejects duplicate identities.                                                                                                                                                                                                          |
| HTML                             | Exports phrasing-content spans carrying a floating kind and a small layout metadata object. Child paragraphs/lists/tables use `span data-rt-block` wrappers with CSS display roles, so a float can live inside a paragraph without browser reparsing moving its blocks. Import reconstructs those blocks from the current visible markup. Floating image geometry and wrap settings also survive HTML round trips. |
| XAML                             | Supports Figure/Floater nodes, `.Blocks` property elements, `FigureLength` units, anchor/wrap properties, and table column property elements. It is an inert portable parser, not a native XAML object loader; markup extensions are rejected.                                                                                                                                                                     |
| Markdown                         | Emits the child story as ordinary Markdown content, retaining supported emphasis, links, lists and tables. Floating placement and the original object boundary are lost.                                                                                                                                                                                                                                           |
| RTF                              | Emits the child story's text, supported inline formatting and paragraph breaks in document order. Floating placement, shape metadata and exact table layout are lost.                                                                                                                                                                                                                                              |

Floating HTML metadata is limited to known properties and 4,096 characters per object. Imported anchors, wrapping values, dimensions, offsets and shapes are validated individually. Invalid values are omitted while safe story text is retained. Unknown `data-rt-block` values do not create arbitrary node types. Active content, event attributes, scriptable URLs and arbitrary CSS continue through the shared HTML sanitizer.

HTML preserves the supported visible table structure and spans; canonical JSON and XAML additionally preserve declared table column definitions. These interchange paths do not establish native Word layout equivalence or retain every proprietary floating-object extension.
